# Unreal Engine - Telekinesis Gameplay Mechanic
This artifact is a gameplay mechanic vertical slice in both Unity and Unreal Engine, exploring the creation of a 'Telekinesis' gameplay mechanic similar to the video game, 'Control'. The aim was to create an easily exportable gameplay system that could be put into a project with minimal setup.

Players are able to pick up specific 'Telekinetic' objects that are highlighted on hover, and are able to throw them at a fast velocity. Players are able to levitate when they are airborne to extend their duration in the air. Players additionally are able to generate a front-facing shield made from debris on the floor.

## Features
- Grabbing/Throwing Objects
- Levitation
- Debris Shield Generation

## Setup and Controls
**To play the game, download the Unreal Build zip folder in releases, extract the folder and run the exe**
| Key         | Action                                       |
|-------------|----------------------------------------------|
| W           | Walk Forward                                 |
| S           | Walk Backward                                |
| A           | Walk Left                                    |
| D           | Walk Right                                   |
| Space       | Jump                                         |
| E           | Grab/Throw Telekinetic Object                |
| F           | Toggle Levitation                            |
| Q           | Create Shield Debris                         |
| Tab         | Swap Camera Position                         |
